The Problem

Colleges struggle with communication chaos and manual administration every day.

  • Scattered communication — Cancellations, exams, and holidays get lost in WhatsApp groups and informal chats.
  • No single source of truth — Students can't tell official notices from random messages.
  • Manual academic admin — Directors and faculty lack one place for departments, rosters, and assignments.
  • Attendance friction — Paper sheets and spreadsheets fail when Theory and Lab need separate records same day.
  • Role confusion — Students, faculty, directors, and CRs all need different tools — but get the same generic channels.

Our Solution

Lecturify centralizes verified college communication and administration in one clean web app.

AreaWhat Lecturify Does
Verified Updates Teachers and CRs post official class updates. Students see a filtered feed — cancellations, exams, schedules, holidays only.
Role-Based Access Separate portals for Student, Faculty, and Director with tailored dashboards and permissions.
Director Admin Academic setup, student directory with profiles, faculty ID management, campus-wide alerts.
Faculty Tools Post updates, digital attendance, student roster, subject teachers, CR management.
Attendance Sheets Theory / Lab sessions, draft & lock, history view, multiple sheets per day.
Demo Ready Pre-loaded director, 2 faculty, 10 students, Robotics & AI class — explore instantly.

Features by Role

Student

  • Official class update feed
  • Campus alerts
  • Filter by update type
  • Class chat
  • Profile management
  • CR posting tools (if assigned)

Faculty

  • Post verified updates
  • Digital attendance (Theory/Lab)
  • Lock sheets & view history
  • Student roster & profiles
  • Add subject teachers
  • Assign Class Representative

Director

  • Campus-wide alerts
  • Department & program setup
  • Student directory + filters
  • Expandable student profiles
  • Faculty ID overview
  • Academic structure management

Tech Stack & Quick Start

Technology

Run the App

git clone https://github.com/avnihere-py/lecturify.git
cd lecturify
npm install
npm run dev

Open http://localhost:5173 in your browser.
